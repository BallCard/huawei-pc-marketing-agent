01 / 理念传递

生态营销，先把“内容”放回经营链路。

生态营销不是多发几个平台，而是让同一份产品事实进入不同的人群、渠道和私域触点，形成可继续跟进的关系。页面里展示的是一条链：人群与场景 → 渠道格式 → 门店目标 → 私域触达 → 到店动作。

生态触点转化

从“一篇文案”变成一组经营参数

创作简报把角色、人群、场景、平台、目标和私域触点显式化。每一项都能改、能复用，也能在生成过程里回看。

人货场触点目标
可指给评委创作简报四步输入我的门店历史与私域触点同一事实按平台重组

02 / 技术升级

从“会写”升级为“会编排、会核验、会回流”。

技术升级不只体现在模型名字，而体现在任务如何被拆开：先理解需求，再读资料、选角度、写作、规则检查、独立评审，发现问题后定向修订。每个阶段都留下可读的处理记录。

ORCHESTRATION / 任务编排一条可解释的生产线
理解拆硬约束与软偏好
→

创作候选角度与平台结构

评审独立上下文交叉核验
01确定性规则

型号、数字、配图、平台字数和合规词有程序检查。

02独立评审

写作与审核使用独立上下文，问题不会被同一个回答自我掩盖。

03定向回流

只修具体问题，再做一次复核；人工只处理重要未决。

03 / 哲学体现

人机交互，不是把人排除在外。

AI 负责穷举、整理和提示，人负责给出边界、做最后判断。页面里最关键的交互不是“点一下生成”，而是需要时会问、过程中看得见、结果里能追责。

A

它敢问，而且只问关键的一点。

需求含糊时触发单轮追问，最多两轮。选项贴近门店场景，也允许自己填写。

B

它把过程摊开，让等待有意义。

当前环节、使用资料、处理耗时和下一步都能看见。过程不是进度条，是可解释的工作记录。

C

它把需要负责的地方交还给人。

自动修订、可选建议、重要未决和误报分开。人只处理真正需要判断的事项。

最后一句

我们展示的不是功能数量，
而是理念如何在功能之间形成一条线。
