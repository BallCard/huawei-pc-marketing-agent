展示版 B · 把功能串成一条任务线

从一句需求，
到一份可以带走的内容。

适合现场边点边讲：每向下走一步，就回答一个评委的问题。它替谁工作？依据从哪里来？生成为什么可信？最后能不能直接用？

任务线01—05输入 / 上下文 / 编排 / 核验 / 交付
观看角度
01

INPUT / 经营参数

先说清楚：
写给谁、发到哪里、要什么结果。

结构化选择与一句话输入并存。门店角色、人群、场景、平台、目标和私域触点共同决定后面的内容。

理念生态营销证据创作简报 · 私域触点
02

CONTEXT / 资料与历史

再看上下文：
这家店有什么，最近写过什么。

已确认的门店资料进入创作上下文，未确认内容不会被拿来凑正文。历史稿用于避重和复盘。

理念门店生态证据我的门店 · 历史沉淀
03

ORCHESTRATION / Agent 接力

它不直接猜答案，
先把工作拆开再接力完成。

理解需求、备料、选角度、写作、规则检查、独立评审和定向修订，各有自己的职责和记录。

理念技术升级证据阶段记录 · 实时耗时 · 资料路径
04

EVIDENCE / 事实核验

写完以后，
每一句主张都能回到原文。

事实、条件、图片型号和审核意见一起展示。系统自动处理确定性问题，把重要未决交给人裁定。

理念人机交互证据事实核验 · 审核分流
05

DELIVERY / 平台原生交付

最后交付的不是一段字，
是可以直接拿去用的内容。

小红书、公众号、朋友圈和门店海报有不同结构；支持电脑端、手机端预览，复制正文和离线 HTML 导出。

理念生态营销证据平台预览 · 二次打磨 · 导出
