# 平台短营销图文

采用平台原生阅读顺序，不把笔记改为桌面左右分栏，也不用折叠、截字或摘要来掩盖长稿。

## 参考与取舍

- [小红书电商学习中心：商品笔记创作](https://school.xiaohongshu.com/lesson/normal/af0fe7e97bb0433fac9da5d1df52b07f)：标题精简，正文抓关键信息，借助短段和空行阅读；课程有图文 100–400 字的建议。结合本工作台用户偏好，默认选择其中更短的一档。
- [华为智慧办公官方图文](https://consumer.huawei.com/cn/smart-office/)：观察的是场景短标题、少量解释配图、条件与正文分层的表达方式；它不是微信公众号原帖。公众号采用这种品牌图文节奏是本项目的编辑选择。
- 本地 P6 平台模板、案例研究用于参考结构；旧模板的公众号 1200–2200 字、小红书 300–800 字不再作为默认篇幅。

只学习表达方式，不复制原文，也不把案例中的产品能力作为本次型号事实。

## 默认成稿

| 平台 | 正文字数 | 阅读节奏 |
| --- | --- | --- |
| 小红书 | 100–220 | 图片轮播 → 短标题 → 3–4 个短段 → 一句互动、话题 |
| 公众号 | 240–480 | 单列向下，图与 2–4 行短文交替，讲清 2–3 个亮点 |
| 朋友圈 | 40–90 | 3–5 个短行，一个亮点、一个行动 |
| 门店海报 | 35–100 | 主标题、少数卖点、简短邀请 |

这些是本项目的默认编辑标准，不是平台发布限制。字数包含导语、正文、行动引导，不含标题、图注、标签。

## 写法与核验

- 一个段落只讲一个意思。候选事实不用全写，先删次要参数和重复背景。
- 小红书最多提供 2 条候选事实，公众号最多 4 条，从源头减少堆卖点的倾向。
- 保留已写主张的版本、配置、“约/最高/可选”与兼容条件；简洁不能改变事实。
- 正文只写和主张有关的简短条件；详细来源、风险分析、待确认清单留在核验页。
- 图注描述画面，示意图须标明；不把长篇“能证明/不能证明”分析当图注发布。
- 平台策略传给写作、修订和审核；总长度与单段长度进入确定性核验，超长时重写，不在前端截断。
