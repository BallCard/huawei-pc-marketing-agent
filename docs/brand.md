# 华章有据

“华”呼应华为，“章”指向图文内容，“有据”指向知识库依据、来源追溯与独立审核。名称强调本项目的创作方式。

Logo 用微微不规则的展开书页表现创作，一枚陶土色圆点表现引用出处。保留现有纸感线稿语言，与过程页 Bot 线条协调。

运行服务后可打开 `/static/brand/index.html` 查看并下载这套方案。

| 资源 | 用途 |
| --- | --- |
| [logo-mark.svg](../src/mvp/web/brand/logo-mark.svg) | 透明底图形，页面导航 |
| [wordmark.svg](../src/mvp/web/brand/wordmark.svg) | 图形与四字名称横排，演示与文档 |
| [app-icon.svg](../src/mvp/web/brand/app-icon.svg) | 带暖白底的方形图标、favicon |

- 配色：暖白 `#f8f7f3`、墨黑 `#25241f`、陶土色 `#b35f42`。
- 字体沿用项目的宋体衬线组合；字标 SVG 的文字保持可编辑，使用时需有对应中文字体。
- 现有项目使用原生 HTML/CSS 与自绘 SVG，因此沿用现有结构与线稿系统，不额外引入 UI 框架或图标依赖。
- 独立开屏依次展示图形、四字名称与一句话功能介绍，点击「进入体验」进入工作台；刷新恢复任务时跳过。支持减少动态效果偏好。导航保留紧凑字标。
