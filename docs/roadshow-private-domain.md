# 路演话术：企微 SOP / 社群运营 / 到店转化

> 用途：路演讲解、评委问答、门店店长沟通。
> 原则：讲**机制**，不编**数字**。凡涉及转化率、GMV、触达率等第三方数据，必须标注来源；没有来源就不说具体数字，改说"口径"和"可验证方式"。

---

## 0. 30 秒电梯稿（背下来）

> 华为门店的营销，难点不在"写文案"，而在三件事：**人是谁、店有什么、下一步让他干什么**。
> 我们的产品把门店资料、私域触点、经营目标变成生成内容的显式输入——店长选一个目标、勾一个触点，产出的就是能直接发到企微、社群、朋友圈、并把人引到店里的内容，而且每个参数都能回溯到知识库原文。

---

## 1. 企微 SOP：把"加了好友"变成"可执行的跟进"

### 一句话
企微不是通讯录，是**一条有节奏的跟进流水线**：谁加的、为什么加、下一步给什么理由。

### 四个环节（SOP 骨架）

| 环节 | 做什么 | 判断标准 |
| --- | --- | --- |
| 承接 | 顾客在什么场景下加企微，当场得到什么好处 | 加微动作是否有"当场价值"，而不是"以后有活动通知你" |
| 分层 | 按需求打标签：购机 / 换机 / 配件 / 企业采购 / 学生 | 标签是否来自真实对话，而不是猜 |
| 触达 | 1v1 给**具体理由**，不是群发广告 | 每条消息是否只服务一个动作 |
| 承接动作 | 到店、预约体验、私信咨询、换新评估 | 有没有明确的"下一步"和入口 |

### 常见误区（路演时用来制造共鸣）
- 把企微当群发工具：一天三条促销，三天被折叠。
- 只发权益不发理由：顾客不知道"为什么是现在"。
- 没有分层：给刚买完的人推购机优惠。
- 没有下一步：聊完就断，没有到店钩子。

### 衡量口径（先埋点，别先吹数字）
- 加微率 = 到店顾客中完成加微的比例
- 有效对话率 = 有来有回的会话 / 总触达
- 到店核销率 = 凭私域邀约到店并完成体验的比例

### 产品里对应什么
- 触点 chips：**企业微信私信**
- 门店目标：**私信咨询 / 引导到店**
- 事实来源：门店资料（服务、库存、活动）+ 产品知识库，不允许模型自由发挥
- 样板：S01 企微承接（待审核）、S05 导购栏目化（待审核）

### 可直接讲的话术
> "店长最常问：加了这么多人，怎么用？我们的回答是——先别想群发，先想清楚这个顾客为什么加你、你下一次给他什么理由。企微 SOP 就是把这两个问题固定成动作：承接有理由、分层有依据、触达有节奏、结尾有下一步。"

## 2. 社群运营：门店三公里内的"熟人圈"

### 一句话
社群不是流量池，是**一个只服务一个目的的房间**：答疑、到店日、或者清库存，一次只做一件事。

### 节奏（三段式）
1. **日常内容**：栏目化输出——答疑、实拍、真实问题记录、到店实况。一条内容只解决一个问题。
2. **集中动作**：接龙 / 报名 / 到店日。给一条**可核对**的理由（体验项目、时间、地点），不是"到店有礼"。
3. **复盘**：这场接龙来了多少人、核销多少、下次改什么。

### 常见误区
- 群当广告群：只发促销，没人说话。
- 天天大促：把价格打成常态，顾客只等降价。
- 编造顾客好评、虚构库存紧张："最后 3 台"结果一直有货。
- 活动信息不落地：说了体验项目，到店没有。

### 衡量口径
- 群活跃（有效发言人数 / 群人数）
- 接龙参与率
- 到店核销率（接龙 → 实际到店）

### 产品里对应什么
- 触点 chips：**门店社群 / 朋友圈**
- 门店目标：**消化库存 / 预约体验**
- 硬门控：社群团购、粉丝活动类样板**必须**引用门店已确认的活动或服务资料，否则不生成——这是产品里真实存在的约束，不是口号
- 样板：S03 社群接龙、S04 会员日邀约（待审核）

### 可直接讲的话术
> "社群最容易死在'没有理由'。所以我们把'活动资料'做成硬门槛：没有门店确认的活动、服务或库存，系统不会给你编一个'到店有礼'。宁可少写一条，也不让店长发一条兑现不了的消息。"

## 3. 到店转化：把线上注意力换成"进店 + 体验 + 成交"

### 一句话
到店不是喊出来的，是**设计出来的动线**：一个具体体验点 → 一个低门槛动作 → 一次可兑现的接待。

### 链路五步
1. **钩子**：一个具体、可体验的项目（不是"来看看"）
2. **预约/报名**：降低决策成本的动作（接龙、私信、电话）
3. **到店接待**：体验动线（先看什么、后看什么、谁接待）
4. **留资/加微**：把这次到店变成下一次触达
5. **复购/换新**：旧机评估、配件、延保

### 常见误区
- 钩子太虚："新品到店"——新品天天到。
- 权益不可兑现：说了赠品，到店没有。
- 没有接待动线：顾客进店没人接，转一圈走了。
- 不留下一次触达：成交即结束。

### 衡量口径
- 预约率 = 预约数 / 内容触达数
- 到店率 = 实际到店 / 预约数
- 体验转化率 = 成交 / 完成体验数

### 产品里对应什么
- 触点 chips：**到店邀约**
- 门店目标：**引导到店 / 预约体验**
- 样板：C16 体验邀请（已审核，正式稿必须引用门店确认的服务/活动）、S04 会员日（待审核）
- 输出形态：海报（门店物料）、朋友圈短文、公众号长文、小红书种草

### 可直接讲的话术
> "到店转化最贵的一步不是成交，是'顾客为什么今天来'。我们把这个问题前置成输入：你选的体验点是什么、门店有没有这个活动、库存够不够。资料不全，系统会直接告诉你缺口，而不是生成一篇漂亮的空话。"

## 4. 三者怎么串成一条链路（路演主叙事）

```
内容（小红书 / 公众号 / 朋友圈 / 海报）
        ↓  私域承接
企微 1v1  ──  门店社群  ──  朋友圈
        ↓  到店动作
邀约 / 预约 / 体验 / 接龙核销
        ↓  复购
换新评估 / 配件 / 延保
```

产品在每一环的作用：
- **内容层**：按平台规格生成，事实可核验
- **承接层**：私域触点决定内容形态（1v1 短、社群可接龙、朋友圈轻、海报可贴）
- **到店层**：门店目标决定 CTA 和到店理由
- **复用层**：门店资料是唯一事实源；历史稿避免重复；发布状态可标记

## 5. 演示串词（对着界面讲，按顺序）

1. **门店状态带**："先看这家店现在有什么——有效资料几条、有没有待确认的、库存和活动记录。"
2. **我的角色**："店长和销售看到的视角不一样，这里可以切。"
3. **写给谁 / 什么场景**："这是内容的对象。"
4. **门店目标**："这次要达成什么：引导到店、预约体验、私信咨询、还是消化库存。"
5. **私域触达轨道**："内容会发到哪里：企微、朋友圈、社群、到店邀约。"
6. **门店资料与近期稿件**："店里的真实资料在这里，最近写过什么也在这里，避免重复。"
7. **开始创作 → 生成过程**："每一步都能看到用了哪条资料。"
8. **作品 + 事实核验**："每个参数都能点回原文；有问题会列出来，不会假装通过。"

## 6. 常见追问 Q&A

**Q：AI 会不会瞎编？**
A：三条约束——产品参数只能来自知识库原文；门店信息只能来自你确认过的资料；生成后还有事实核验和审核问题清单。缺资料时它会告诉你缺口，而不是编一个。

**Q：和通用大模型写文案有什么区别？**
A：通用模型不知道你店里有什么。我们把门店资料、触点、目标变成结构化输入，再用已审核的营销样板约束结构——模仿的是"打法"，不是抄文案。

**Q：店长会用吗？**
A：三个输入（写给谁、发哪里、要什么结果）+ 一个按钮。门店资料一次录入，之后每次生成自动带上。

**Q：效果怎么衡量？**
A：先埋三个口径：加微率、到店核销率、内容产出量。没有基线之前不承诺提升百分比。

**Q：数据安全？**
A：门店资料存在本地/私有库，按门店编号隔离；对外部署走登录和 HTTPS。真实客户个人信息不进入公开方法库。

**Q：为什么样板要审核？**
A：样板决定结构，结构会带出承诺。未经审核的案例不进入生成链路，避免把别人的打法和我们的品牌混在一起。

## 7. 不能说的话（合规红线）

- 不编造转化率、GMV、触达率等数字；引用第三方数据必须带来源。
- 不暗示华为官方授权、联名或官方活动（除非确有授权）。
- 不虚构库存、价格、赠品、名额。
- 引用友商案例只说"模式参考"，不说"合作"或"对标"。
- 不承诺"AI 写的稿子一定能爆"。

## 8. 三个时长版本

**30 秒**：门店营销难在人、货、下一步。我们把门店资料、私域触点、经营目标变成输入，生成能直接发出去、且每个参数可回溯的内容。

**90 秒**：在 30 秒基础上加一句链路——内容在小红书/公众号/朋友圈/海报，承接在企微和社群，落点在到店体验，复购在换新。产品负责每一环的"有据"和"不重复"。

**3 分钟**：加演示串词（第 5 节）和一个真实约束案例——"没有门店确认的活动资料，社群团购类内容不会生成"，用来说明产品不是"什么都敢写"。
