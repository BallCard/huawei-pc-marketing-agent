# 整图海报与用户终审

门店海报默认使用魔搭异步生图，整张图及文字均由模型生成；也已提供 ChatGPT / Gemini 网页反代适配，当前用户选择 ChatGPT，配置与未完成的实测条件见 [网页生图反代](web-image-proxy.md)。其他平台继续使用登记图片与原生版式。

## 内置参考

用户于 2026-10-20 审核并选择了 A、B 两张，清单与文件摘要位于 `src/mvp/web/poster-references/manifest.json`：

- **清新大留白**：[原页面](https://i.ifeng.com/c/8ZRHVcKxnoT)，适合校园、通勤上课、图书馆等场景。
- **极简产品展示**：[华为原页面](https://www.huawei.com/fr/)，作为其他场景的默认视觉参考。

参考只提供构图、配色和文字层级。原图的价格、日期、型号、卖点与活动不能成为本稿的产品事实。原参考完整留存并校验摘要；模型收到的风格输入经过模糊去文字处理，与本型号干净整机图分别输入，减少照搬旧海报和混入其他产品外观。派生风格图也记录摘要。

## 流程与配置

文案策划、规则检查及独立评审通过后，再提交支持多参考图的 `Qwen/Qwen-Image-Edit-2511`。该模型已通过实际任务提交核验，不能仅依赖 `/models` 清单判断可用性。若文案仍有异议，使用者可以在“问题详情”里修订、复审或人工裁定后继续。生图密钥使用独立的 `POSTER_IMAGE_API_KEY`，只在服务端和平台 Secret 中保存。

文案仍使用现有时间预算。生图默认独立等待 600 秒，成图审核默认 60 秒；实测免费推理任务可排队超过 5 分钟，界面只显示真实状态和已等待时间。任务 ID 随进度持久保存，刷新只查询原任务；生图等待超时后“继续等待本次生图”复用提供方任务 ID，不再次提交生图。已返回图片的“重新生图”由用户手动触发。

`Qwen/Qwen3.5-35B-A3B` 先在没有目标文案和产品事实的上下文中独立转录图片文字，再对照产品图、批准文案和证据审图。代码检查独立转录中是否保留批准文案、数字及限定词，后续审核不能把目标文案抄回转录来绕过检查。审核失败或不完整时保留待复核状态，不能借用文案审核或上一张图的通过结论。

生成图片保存在 `POSTER_DIR/<job-id>/poster.png`，默认与任务数据库同级；部署使用持久目录。图片通过登录保护的任务接口读取，文件摘要不匹配时不提供下载。支持 PNG 下载及嵌入图片的离线 HTML，前端不另叠加营销文字。历史 HTML 海报继续兼容。

## 终审反馈

作品页、审核记录和终审过程卡片提供“问题详情”，打开悬浮问答，一次处理一个真实问题：

1. 接受意见，按建议修改。
2. 认为原文可用，填写判断理由。
3. 暂时无法确认。

最后可选择“按反馈修订与复审”“人工裁定采用本稿”或“暂缓处理”。人工采用要求逐项确认原文可用并填写理由。用户说明仅作为复审输入，不直接成为产品事实。未确认项继续保留待复核。

人工结论独立保存在 `human_review` 和任务裁定历史里，不改写模型原始结论，也不会显示成“自动核验通过”。修订从原始稿件、证据和立意继续；每个新版本重新审核。只有图片问题时，修改意见触发手动重生，异议复审检查同一张图片。

接口：

- `GET /api/job/{id}/review`：当前版本的问题、依据和裁定令牌。
- `POST /api/job/{id}/review`：提交逐项选择及最终处理方式；旧稿件令牌拒绝写入。
- `POST /api/job/{id}/poster/regenerate`：手动重新生图或继续等待已提交任务。
- `GET /api/job/{id}/poster/image`：预览；`?download=1` 下载 PNG。

未接入门店真实二维码，生成文案以到店或向店员咨询为行动引导。
