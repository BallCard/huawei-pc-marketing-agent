# 创作上下文：使用与边界

2026-10-22 更新：B 使用用户已批准的 11 个具体营销样板，取代下文初版的六方法候选；样板与填槽、门店资料、历史和实际重合结果均进入生成上下文。概念演示使用独立 D 资料和可见标识，不记入真实门店历史。入口、限制与验证见 [用户审核样板版](reviewed-patterns.md)。A 保留原始提示词。

本轮在本地实现，尚未部署。继续使用现有四个平台与一份成稿的交付方式。

## 怎么用

创作页右上角打开「我的门店」，在「管理门店资料」中输入门店编号并“载入此门店”，再填写名称、常见客群和语气。逐条添加门店信息、服务、库存、活动、真实问题记录或照片文字说明。只有填写来源、确认日期并勾选“已核对”的条目才进入生成依据；库存和活动还必须有有效截止日期。未确认和过期条目只传入不可用状态，不向模型传入正文。

目前的素材录入是文字记录。照片说明不代表已经读取照片，不提供实拍图片上传、视觉核验或直接配图；配图仍由原来已登记的知识库和官方补图机制提供。问题记录只证明问题存在，不能证明答案。名称和客群是用户设置，不可据此推导地址、服务、活动或库存。

保存后，后续创作由服务端读取资料。浏览器不能自带“已核验上下文”绕过保存与字段校验。已有作品保留生成时的快照，用户继续复审时沿用该快照；新创作则重新读取有效资料与历史。活动变化或隔日发布前仍应复核。

作品页展开「本次差异化依据与历史重合」，可查看载入资料数量、实际选中的 C 编号、叙事结构、避重说明、重合片段和备用角度。点击备用角度会填入修改要求，再点击“开始打磨”。“手动标记已发布”只记录用户确认状态，不向任何平台发布内容。

## 实际送给模型的内容

| 阶段 | 实际输入与处理 |
| --- | --- |
| 需求理解 | 门店客群与语气，加原始任务；不从门店推导产品能力 |
| 策划 | 有效确认条目、六个有来源的方法、该门店最近 20 篇历史、平台可用结构与字数预算；比较两个角度，保留任务、收获、结构和避重说明 |
| 写作 | 同一快照、选定角度、结构与产品 F 引用／门店 C 引用；输出仍是一篇 |
| 审核 | 同一快照、实际初稿的字面重合结果、完整 F/C 原文与来源；区分产品事实风险和表达建议 |
| 修订 | 同一快照、实际重合位置、审核意见、已有稿件及事实条件；最多沿用一次自动修订，随后复核实际终稿 |

产品原文使用 F 编号，门店确认资料使用 C 编号，各自展示来源。C 不能证明产品性能，方法库和历史稿不能进入事实引用。未经确认的资料不作为“待补全事实”让模型自行填空。

## 历史、缓存与相似检查

历史保存在现有私有任务 SQLite 的独立表中，不随任务快照最多保留 30 条的规则删除。启动时幂等整理仍保留的已完成稿件；无法找回以前已被清理的任务。现有 9 篇本地稿已导入，均未标记发布，门店归属标为“旧稿，门店未登记”，暂存 default 参考范围；其他门店编号不会读取这些稿件。真实门店资料目前为空。

每次取该门店最新 20 篇生成历史，含发布状态、审核状态、标题、读者任务、结构与正文。并非只参考已发布稿件。后续修订沿用生成前快照，显式排除原稿和父稿。长期保存不等于全库查重，本轮没有跨门店全库扫描。

资料、历史、发布状态、方法或提示词变化会改变策划输入／版本，从而使旧策划缓存失效；需求理解缓存只关心客群、语气及原始任务。写作和审核继续真实调用模型。未修改采样温度，也不推测供应商的实际默认值。

字面检查使用规范化文字与 SequenceMatcher：句段相似比值至少 0.72 且连续重合至少 8 字，或连续重合至少 18 字，才列为提示。标题少于 8 字、其他句段少于 12 字不检测。标出双方句段位置、原文和重合部分。接近产品证据原句及完整条件的重合另列；通用行动邀请不自动触发改稿。最多把两个可改表达提示送入一次修订。

这是可解释的字面重合启发式，阈值尚未由标注语料校准，不能发现所有同义改写或语义重复，也不是原创率。残留重合独立展示，不冒充产品事实审核失败；事实审核通过也不表示文案已足够差异化。

## 隔离与验证

门店编号用于共享演示账号下的资料分组，**没有多租户权限隔离**。有登录权限的人可切换门店编号。产品资料、门店资料、正文历史和测试产物均在忽略提交的 data/ 下；不能将真实客户个人信息写入公开方法库。

自动化验证命令：

```powershell
python -X utf8 -m unittest discover -s tests -p "test_*.py"
node --test tests/*.cjs
```

本轮新增测试覆盖：确认条件与有效期、服务端上下文注入、登录保护、门店分组、历史在任务清理和重启后仍保留、默认未发布、幂等导入、缓存随资料／历史失效、C 引用过滤、四个环节的实际入参、重合定位与证据原句分流、重复触发一次修订。浏览器用隔离的 data/context-validation/ 数据库检查桌面、手机表单与发布标记，不写入真实门店资料。

真实模型样本和验证记录留在 data/context-validation/；样本数量很少，不构成创意提升或营销效果结论。具体结果见本轮汇报。

提示词双版本、可操作的对照入口和各轮真实成稿结论见 [提示词双版本与对照](prompt-comparison.md)。正常创作默认 A；用户可选择 B。固定条件对照的草稿独立保存，不自动加入门店历史。
