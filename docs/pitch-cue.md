# 提词卡（上台只看这一页）

## 一、逻辑主线：五句话

1. **给谁用**：华为门店店长和销售，做私域客群经营。
2. **解决什么**：不是写不出字，是"人是谁、店有什么、下一步让他干什么"三件事同时要成立。
3. **怎么解决**：把这些变成**结构化输入**（人 / 平台 / 目标 / 触点），再走一条**完整复现的写作工作流**。
4. **凭什么信**：产品事实只认官方资料，写完有独立审核，每条主张能点回原文。
5. **人机怎么分工**：AI 判能判的、改能改的；人只判涉及承诺的那几条。

> 五句话讲完，剩下全是"指给他看"。

**收尾句（背下来）**
> 它交付的不是一篇文章，是一条有证据、有边界、能复用的门店内容产线。

## 三、名词纠正（六条，记这六个别说错）

| 别说 | 说 |
| --- | --- |
| 软文 | 品牌原生内容 / 私域内容 |
| 圈粉 | 需求收敛 / 意向分层 |
| 成分分析 | 指标权重分解（加权） |
| 微调 | 定向修订 |
| 交叉验证 | 交叉核对 |
| 生图（泛指所有配图） | 只有门店海报是生成的，其余配图来自官方图库 |

**三句不能说的话**
1. 不说"联网核实参数"——联网只补图，文字事实只来自资料包。
2. 不说"把产品图放进场景重新生成"——产品是原样抠图排版，不重绘外观。
3. 不说"零幻觉 / 全自动可发 / 千店不重复"。

## 四、新人体验的卡点（按严重度，建议开演前处理前三条）

| # | 卡点 | 实际表现 | 评委可能想 | 一句话修法 |
| --- | --- | --- | --- | --- |
| 1 | **首屏状态带是空的** | 进入后顶部显示"未登记门店 · 0 条有效资料 · 暂无库存/活动记录"，但有 12 篇历史 | "是不是没配好？" | 演示前给 demo 门店填 3–5 条**已核对**资料；或把文案改成"演示门店" |

**结论**：整体动线是通的，空状态和错误状态都有兜底。**真正会让人卡住的只有第 1 和第 2 条**——一个让他第一眼觉得"没东西"，一个让他不知道已经结束了。这两条不改代码也能靠演示串词绕过去，但改了会稳很多。
