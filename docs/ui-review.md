# 极简交互预览

运行应用后打开 `http://127.0.0.1:7860/static/ui-review/index.html`。本次本机预览服务使用端口 `7882`。

按用户反馈重新采用极简方向，入口直接展示当前方案。顶部导航可查看创作简报、生成过程、图文作品、事实核验。链接中的 `#s=process` 可直接定位页面，旧评审链接仍可打开对应区域。

设计目的：压低界面信息密度，使每页只有当前任务和主要操作。次要设置、过程记录、修改工具、来源内容按需展开。

视觉规范：白色 `#ffffff`、文字 `#222222`、次要文字 `#777777`、分隔线 `#e9e9e9`。正文与标题使用项目自带的 Noto Sans SC，品牌小字标保留 Noto Serif SC。采用留白充分的单列布局；作品页以产品图和正文为主体。根据用户明确要求使用规则布局，移除大标题、装饰图、侧栏、摘要卡片、评审条和固定底栏。

| 页面 | 默认展示 | 按需查看 |
| --- | --- | --- |
| 创作简报 | 输入框、平台、型号、开始按钮 | 场景示例与内容偏好 |
| 生成过程 | 当前环节、一条进度线 | 环节记录与说明 |
| 图文作品 | 图片、文案、复制与导出 | 修改弹窗、配图与设备切换 |
| 事实核验 | 事实列表、来源状态 | 原文片段和适用条件 |

遵循原生 HTML/CSS 和本地图标规范；未引入框架、外部字体或 CDN。产品图通过现有 `/img/` 接口读取登记资源，资料文件没有复制进 Git。

本页是独立视觉原型，进度和改写使用明确标注的示例。文案可复制或导出 TXT，输入与设置保存在本机浏览器。没有创建任务、模型调用、实际审核或发布请求。

手机端优先一屏展示创作入口；更小的屏幕和长内容允许上下滚动，保留可读字号与按钮点击区域。输入控件使用 16px 字号，导航、弹窗和底部提示适配安全区。

移动适配检查覆盖 320、360、390、430、667、768、900、1440 八种宽度，包含横屏、四个页面、四平台作品、长表格与弹窗，共 152 项浏览器布局检查。运行 `node scripts/check_mobile_ui.cjs`（需可用的 Playwright 与 Edge）；截图与记录位于本机 `data/ui-checks/mobile/`。正式工作台也已加入手机样式，后端无需改动。
