**从产品知识出发，生成有据可查的华为电脑营销图文。**

v1.2.0（version1.2）· 两轮问询与评审减负。[在线体验](https://ballcard-huazhang-youju.ms.show) · [图文介绍](https://ballcard-huazhang-youju.ms.show/about) · [魔搭主页](https://modelscope.cn/studios/BallCard/huazhang-youju) · [部署与配置](docs/deployment.md)

> 个人项目副本，独立于比赛协作仓库。产品资料不进入 GitHub，仅在本机和已授权的私有创空间保留部署副本。
本项目与初赛仓库的关系、当前主线和冻结边界见[两个华为项目的统一说明](docs/project-lineage.md)。后续功能、修复、发布和部署均以本复赛仓库为准；初赛仓库仅作历史参考，不再继续更新。

[切题检验与复赛优化分析](docs/competition-fit-review.md)（2026-10-21）：对照原始手册和老师补充的业务痛点，记录当前缺口、验证边界与优先级。本机手册和知识库原始压缩包归档于 `data/ref/`，不进入 Git。

[复赛演示脚本与视频制作](docs/demo-video-script.md)：真实任务录屏、中文 AI 配音、同步字幕与重点推近；本机成品在 `output/demo/`，素材和缓存在 `data/demo-*`，均位于 D 盘。

v1.2 统一文字角色为魔搭 DeepSeek 1017，需求问询最多两轮；交叉评审先消解轻微意见与有据误报，只把重要未决交人工。答完后可直接点击固定的“提交评审结果”，继续修订或复审。整图海报、慢速回传和手机布局也一并更新。详见 [版本记录](CHANGELOG.md) 和 [编排与验证说明](docs/editorial-workflow.md)。

全站字体现由网站提供：Noto Serif SC 负责标题，Noto Sans SC 负责正文与操作，统一字重和文字层级；HTML 导出会嵌入所需字体。详见 [字体规范](docs/typography.md)。

下一版差异化已在本地接入：门店确认资料、文字素材、近期稿件和实际重合结果进入策划/写作/审核/修订。右上角「我的门店」提供经营看板与历史稿件，门店资料在「管理门店资料」中维护；默认一份成稿，可选择备用角度。案例与评委演示建议见 [差异化调查简报](docs/differentiation-report.md)，使用与验证边界见 [创作上下文说明](docs/creative-context.md)。线上版本随本次部署同步更新。

提示词保留 A 原版与 B 新版，默认 A；「内容偏好」可切换，「生成 A/B 对照」在相同策划、证据、资料与模型下各写一稿并列查看。实验范围与运行方式见 [提示词双版本对照](docs/prompt-comparison.md)。

## 快速体验

打开[体验入口](https://ballcard-huazhang-youju.ms.show)，魔搭会自动跳转到全屏创空间页面。公开演示无需工作台账号、魔搭账号或模型密钥。点击「进入体验」后，选择「试试示例」，或写一句自己的需求，再开始创作。生成后可查看配图与事实来源、复制正文、导出含图片的 HTML。

创空间使用 `protected` 模式：应用入口公开可访问，代码仓库与产品资料包隐藏。公开演示由 `PUBLIC_ACCESS=1` 显式关闭工作台登录；需要恢复账号时，在部署配置中配置 `AUTH_USERNAME` / `AUTH_PASSWORD` 并去掉该开关。

## 模型与资料

v1.2 部署统一文字角色模型；本机以 `.env` 为准。

| 环节 | 当前部署模型 | 调用来源 |
| --- | --- | --- |
| 场景解析、推荐、证据选择与内容策划 | `deepseek-ai/DeepSeek-V4.1-Flash-1017` | 魔搭推理 API |
| 图文写作与定向修订 | `deepseek-ai/DeepSeek-V4.1-Flash-1017` | 魔搭推理 API |
| 独立审核 | `deepseek-ai/DeepSeek-V4.1-Flash-1017`，独立调用与上下文 | 魔搭推理 API |
| 图片核验与海报视觉审核 | `Qwen/Qwen3.5-35B-A3B`，独立视觉调用 | 魔搭推理 API |
| 数字、型号、图片登记、篇幅与合规规则 | 本地 Python 规则 | 无模型调用 |

部署版文本与独立成图审核走魔搭；门店海报经美国 VPS 的私有 worker 调用本人 ChatGPT 网页账号，使用网页账号的生图额度。主链路明确失败时降级一次到魔搭免费 `Qwen/Qwen-Image-Edit-2511`，作品会标注“免费备选链路，待复核”，中文文字仍需人工核对。不调用 DeepSeek 官方 API。知识库使用已预置的产品资料包，图片描述已离线预计算。IMA 实时读取尚未实现，访问者不需要另配资料源或密钥。

## 运行

```bash
pip install -r src/mvp/requirements.txt
python -X utf8 -m src.mvp.app        # http://127.0.0.1:7860
```

也可以双击 `start.cmd`。首次运行将 `.env.example` 复制为 `.env`，放好 `data/kb` 资料包与 `data/cache/vision.json`。文字模型通过 OpenAI 兼容接口统一调用魔搭 DeepSeek 1017，需在服务端配置魔搭令牌。

启动前可运行 `python -X utf8 scripts/preflight.py`；加 `--check-model` 会真实调用三个角色模型检查 JSON 返回。部署专用配置可用环境变量 `APP_ENV_FILE=.env.deploy` 指定，不覆盖本机 `.env`。

## 功能

- **用户审核样板版（本地）**：A 保留原始提示词并保持默认，B 从审核通过的 11 个 PC 营销案例匹配和填槽，可指定样板并查看来源、备注及引用；支持概念演示标识和并排 A/B 对照。用法与验证边界见[用户审核样板版](docs/reviewed-patterns.md)。

- **独立开屏**：Logo、名称与一句话描述依次出现，点击「进入体验」进入工作台；同一标签页刷新或恢复任务时跳过，支持减少动态效果。
- **平台原生版式预览**：顶部切换电脑 / 手机并保留选择；电脑端小红书左图右文、公众号宽栏阅读、朋友圈桌面动态流，手机端保留图片轮播与九宫格，门店竖版海报维持原样。窄屏首次默认手机模式，电脑首次默认电脑模式。
- **两种场景输入**：结构化选择人群与使用场景，或直接用一句话描述需求；机型留空时按需求推荐。
- **一屏一页**：创作简报 → 生成过程 → 图文作品，事实核验单独查看；图文只在预览区内滚动，操作始终可见。
- **悬浮追问**：需要补充信息时不再挤占生成过程页，改为居中悬浮对话逐条询问，过程页压暗成磨砂背景；每轮只问一个关键问题，每题自带 2–4 个贴合实际场景的选项和自写入口，选中即继续，不再多点一次确认；最多两轮，第二轮根据已答内容递进确认，型号消歧也计入上限。续跑时已完成环节定格，过程页从当前环节继续，不从头回放；两轮后能继续则将未知事项列入待确认；无法安全选型则说明原因并返回简报；切页、收起或刷新后已回答内容仍保留。
- **轻量 Bot 轮转**：保留手绘 Bot，每次展示一个环节与加载动画，直接列出本次知识库文件、原文片段、图片和实际检查项；下一环节柔和浮现，上一环节向下退场。联网访问仅由真实工具事件触发，缓存单独标明；刷新恢复当前状态，动画不影响查看作品。
- **场景示例**：内置常见场景，先填入简报，修改后再开始生成。
- **证据优先**：产品事实只来自知识库，逐条标注来源；图片使用知识库登记图，缺整机图时允许联网检索华为官网。
- **按需报价**：四个平台都允许在与任务相关且有对应官方价格快照时报价，保留配置、价格类型、核验日期和条件。默认不添加“不提价格”的用户限制；用户明确要求不提时遵从，缺依据不编造，无关价格不追加提醒。
- **图片画面分类与联网补图**：整机优先，首图必须是整机图；缺图时优先读取已登记的华为官方产品页，必要时通过联网搜索发现官网页面。仅采用完整型号匹配、产品专属路径、尺寸与视觉检查均通过的整机图，保存原网页、原图 URL、核验时间及文件摘要；七天内复用缓存，下载与导出走本地已核验文件。来源或画面无法确认、联网失败、视觉模型不支持时仍显示缺图。可用 `WEB_IMAGE_SEARCH=0` 关闭，`IMAGE_VERIFY_MODEL` 默认使用支持视觉输入的 Qwen，接口独立于文字模型。
- **策划—核验—定向修订—复核**：完整证据与适用条件分开管理；规则检查与独立评审并行，问题推动最多一次修改，必要时补查本型号，实际终稿未通过则保留待复核。
- **平台短文案**：小红书 100–220 字、公众号 240–480 字，按平台原生图文顺序输出；总字数、单段、标题与图注上限均参与核验。写法与来源见 [风格说明](docs/writing-style.md)。
- **小范围展示部署**：可选的 Cookie 登录、单实例并发限制、SQLite 保存任务与结果；重启后保留已完成作品，未完成任务明确标记为中断。
- **模型分工**：FAST / WRITER / JUDGE 统一使用魔搭 `deepseek-ai/DeepSeek-V4.1-Flash-1017`，覆盖解析、推荐、策划、写作、修订和文字评审；评审上下文独立。生图及图片核验使用专用模型，密钥只保存在服务端。
- **评审分流**：文字稿的重要争议由 DeepSeek 1017 在独立上下文交叉核对，撤销事实风险需通过原句、引用和完整条件校验。轻微表达建议不阻塞交付；确定错误沿用一次自动修订，剩余错误可一键继续修订，审核中断可重试。仅重要未决交人工，同一具体根因合并并保留全部位置与原始意见。
- **门店整图海报与用户终审**：使用已由用户选定的两张内置视觉参考，生成整张海报，再核对成图文字、产品外观与场景。重要视觉争议独立看图复核，文字转录和尺寸检查保留。支持 PNG 下载、手动重生和超时后继续等待原任务；仅重要未决事项需要人工选择修订、复审、采用或暂缓，人工裁定与自动审核分开记录。配置与接口见[海报生成说明](docs/poster-generation.md)。[魔搭与美国 VPS 的私有出图链路](docs/web-image-proxy.md)已连接，真实 GPT 样张约 29 秒返回，产品外观细节仍需终审。

## 速度

- 首发部署记录的小红书样例约 30 秒。默认总预算现为 240 秒，覆盖质量模型的写作、独立评审及一次修订/复审；这是耗时上限，完成即返回。90 秒会截断部分质量档评审，约一分钟的目标尚未达到；真实耗时通过 [三版本对照脚本](scripts/evaluate_editorial.py) 记录。
- 文字角色统一使用 DeepSeek 1017；内容偏好里只保留传播目标与额外限制，提示词 A/B 收进「实验设置」，不再提供没有实际差异的档位下拉。重复输入可复用需求与策划缓存；资料和提示词版本变化后失效，写作和审核仍真实调用模型。

## 说明

- `data/`、`.env`、`.env.deploy`、`model.txt` 均不进入 GitHub；换机器时需要重新放置资料与密钥。魔搭部署资料只同步到指定私有创空间。
- v1.2 使用本地资料包；IMA 实时读取、ZIP 上传、管理员配置面板与多用户隔离尚未实现。
- 当前为公开演示（`PUBLIC_ACCESS=1`），不需要工作台账号；生成后可复制正文、导出含图片的 HTML，不会自动发布到社交平台。
- 没有依据的价格、补贴、库存、销量、奖项不得写入稿件；发布前以官方渠道为准。
- 图片视觉标签可用 `python -X utf8 -m src.mvp.tag_images` 重新生成，默认调用独立的视觉核验模型。
