# 华为 PC 营销软文智能体（本地版）

一个按平台版式输出图文营销稿的本地 Agent 工作台：从知识库取事实，按小红书 / 公众号 / 朋友圈 / 门店海报的原生版式排版，并对事实、图片型号和合规做核验。

> 个人项目副本，独立于比赛协作仓库。知识库为本地只读副本，不入库、不外传。

## 运行

```bash
pip install -r src/mvp/requirements.txt
python -X utf8 -m src.mvp.app        # http://127.0.0.1:7860
```

也可以双击 `start.cmd`。模型走 OpenAI 兼容接口，默认指向本机反代（见 `.env`）。

## 功能

- **平台原生版式预览**：小红书手机笔记（图片轮播 + 话题标签）、公众号长文（作者行 + 通栏图注）、朋友圈九宫格、门店竖版海报。
- **Agent 编排可视化**：纵向时间线 + 机器人图标，默认折叠；点任一环节展开该步真实输入输出与耗时。
- **一键测试**：内置常见场景，点一下直接运行。
- **证据优先**：产品事实只来自知识库，逐条标注来源；图片只用 `图片索引.csv` 登记文件。
- **图片画面分类**：视觉模型离线给全库图片打标签（整机 / 场景 / 局部 / 屏幕 / 示意 / 标志 / 人物）；选图时整机优先，首图必须是整机图；型号没有整机图时明确提示，不拿其他型号顶替。
- **核验—修订—独立审核**：数字、型号、图片、价格、合规规则表 + 独立审核模型。

## 速度

- 质量优先（写作 high / 审核 medium / 解析与提取 low）：约 55–65 秒。
- 极速演示（全部 low）：约 30 秒冷启动；同输入重复运行命中场景与事实缓存，约 15–20 秒。
- 页面左侧“生成档位”可直接切换。

## 目录

```text
src/mvp/
  app.py          FastAPI 服务
  pipeline.py     编排流程、核验、缓存
  kb.py           知识库读取与图片索引
  verify.py       确定性核验
  llm.py          模型调用
  tag_images.py   图片视觉标签生成
  config/         场景与平台策略表
  prompts/        各环节提示词
  web/            前端（无构建步骤）
data/kb/          知识库本地副本（gitignore）
data/cache/       视觉标签缓存（gitignore）
```

## 说明

- `data/` 与 `.env` 均不入库；换机器时需要重新放置知识库副本。
- 没有依据的价格、补贴、库存、销量、奖项不得写入稿件；发布前以官方渠道为准。
- 图片视觉标签可用 `python -X utf8 -m src.mvp.tag_images --model gemini-3.8-flash-low` 重新生成。
