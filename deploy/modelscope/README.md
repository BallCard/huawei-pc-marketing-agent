# 华章有据

[图文介绍与真实截图](https://ballcard-huazhang-youju.ms.show/about) · [进入体验](https://ballcard-huazhang-youju.ms.show)

**v1.2.0（version1.2）· 从产品知识出发，生成有据可查的华为电脑营销图文。**

华章有据把产品资料、用户场景和平台版式连接起来：输入目标人群与使用场景，生成适配小红书、公众号、朋友圈或门店海报的营销图文，同时保留事实出处、图片登记与独立审核记录。

[进入独立体验页](https://ballcard-huazhang-youju.ms.show) · [GitHub 项目](https://github.com/BallCard/huawei-pc-marketing-agent)

面向队友及评委的小范围演示，请使用作者单独提供的演示账号。无需注册魔搭，无需填写模型 API。创空间采用保护模式，应用入口开放，源码与资料包保持隐藏。GitHub 仓库按作者当前授权范围开放。

## version1.2 更新 · 2026-10-21

- 文字模型统一为魔搭 DeepSeek 1017；问询每轮只确认一点，最多两轮，选项随实际问题递进。
- 重要争议先交叉核对，轻微建议不阻塞；确定错误自动修订，仅重要未决交人工，同根因合并展示。
- 评审答完后点击底部固定的“提交评审结果”，可直接继续修改或复审；返回、重开与失败重试均保留答案。
- 整图海报支持专用出图通道、PNG 下载、视觉复核与手动重生；慢速回传可继续等待原任务，手机布局同步改进。

完整记录见 [GitHub 更新说明](https://github.com/BallCard/huawei-pc-marketing-agent/releases/tag/v1.2.0)。

## 用一分钟认识它

1. 登录后点击「进入体验」，从场景示例开始，或直接说一句需求。
2. 选择发布平台；指定电脑型号，或留空按需求推荐。
3. 观察 Bot 单环节轮转，查看实际场景、资料来源、处理结果与实时进度。
4. 阅读图文作品，核对事实与配图；有疑点时按审核提示复核，再复制或导出。

## Agent 接力

内容策划、创作编辑与独立评审分工协作，由代码控制流程。过程页保留手绘 Bot，每次展示一个环节的真实操作、资料来源与加载状态；横向进展随实际执行推进。审核问题最多触发一次定向修订，之后复核实际终稿。

## 事实与配图有据可查

产品事实标注资料片段，图片限定为对应型号的登记文件。没有整机图时明确提示，不拿其他型号图片代替。数字、型号、合规与篇幅规则先检查，独立审核再看最终稿；存在异议时保留人工复核提示。

![事实核验](https://ballcard-huazhang-youju.ms.show/static/gallery/evidence.jpg)

## 模型分工

- DeepSeek-V4.1-Flash-1017：统一负责场景解析、选型推荐、证据选择、内容策划、写作、定向修订与文字审核；评审使用独立上下文。
- 生图与图片核验使用各自的专用模型。需求确认每轮一个关键问题，最多两轮，选项随问题生成，第二轮依据已有回答递进。
- 文字与视觉核验请求通过魔搭推理 API；海报出图按专用通道配置执行。访问者无需填密钥。
- 产品资料来自预置资料包，视觉标签已离线预计算。本版尚未接入 IMA 实时知识库。

## 演示说明

v1.2 面向小范围展示，同一时间最多生成一个任务；如提示正在创作，稍后再试。默认总预算上限 240 秒，完成即返回，实际受模型排队和修订影响；审核未完成或仍有问题时保留明确状态。全站使用随应用提供的 Noto 字体，HTML 导出嵌入所需字体。

生成内容用于辅助创作，发布前仍需人工复核产品版本、软件适配及销售条件。不会自动发布到小红书或微信。知识库事实基准日：2026-10-17。
