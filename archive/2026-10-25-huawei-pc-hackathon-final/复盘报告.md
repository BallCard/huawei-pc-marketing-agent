# 比赛复盘：ZJUshaaa · PC-Studio

## 1. 结果先定准

`ZJUshaaa / PC-Studio` 在华为赛道排名第 5，得分 74.22，按最终成绩截图的分组获得二等奖。与第 4 名相差 2.91 分，与第 1 名相差 6.40 分。归档中没有评委逐项评分或文字反馈，所以不能把某个具体问题直接认定为失分原因。

当前根目录的交付材料主要使用“华章有据”命名，代码和说明也围绕华为电脑营销图文工作台展开。本次复盘把两层信息分开：成绩和队伍身份以用户确认的 `ZJUshaaa / PC-Studio` 为准；材料能力、版本记录和工程问题只按归档里实际存在的文件来判断，不把文件名自动改写成评委结论。

## 2. 这次归档做得好的地方

### 交付物齐全

根目录曾经同时存在项目说明书、产品介绍 PPT、演示视频、离线展示包、案例审核 JSON 和入围名单 PDF，说明比赛提交和展示所需的主要材料都已留下。现在这些成品集中到 `deliverables/`，结果证据集中到 `results/`，关键文档快照放到 `notes/`，后续查找成本明显降低。

### 工程材料有可追溯记录

归档保留了 README、CHANGELOG、验收记录、部署说明、演示脚本、案例 JSON 和工作区补丁。此前的工程记录还包含 140 项 Python 测试、32 项前端测试及页面适配检查；这些可以作为实现和状态控制证据，方便以后重演当时的版本。

### 结果证据被单独保存

最终成绩截图与“决赛入围名单”被明确区分：前者用于确认最终名次和奖项，后者只证明曾进入决赛材料范围。这个区分避免把入围文件误当成最终成绩单。

## 3. 当前最需要改进的地方

### 队伍名和项目名必须统一

这是本次发现的首要问题。最终成绩截图是 `ZJUshaaa / PC-Studio`，而根目录材料大量使用“华章有据”，此前归档还误写成 `byai / 华为PC营销图文工作台`。如果直接把现有 PPT、视频、Logo、介绍页交给外部评审，容易产生“材料属于哪支队伍”的疑问，也会削弱成绩与作品之间的对应关系。

下一次提交前应做一次身份冻结：队伍名、项目名、Logo、开屏、页脚、视频片尾、PPT 封面、压缩包名称和线上链接全部从同一个配置或清单生成；旧名称只能作为历史版本说明，不能继续出现在最终交付物的主视觉中。

### 作品证据和成绩证据还没有一一对应

目前成绩截图能够确认名次，但归档材料没有一份“PC-Studio 最终提交包”的索引，无法快速回答每个视频、PPT、说明书属于哪个最终版本、对应哪次演示、由谁确认。以后应在提交前生成一页总表，记录文件摘要、版本、演示入口、提交时间和最终确认人。

### 评审反馈缺失，不能只凭分数猜原因

74.22 分说明作品完成了参赛要求并获得二等奖，但分数本身无法说明是创意、技术、表达、完成度还是现场演示拖后腿。复盘时不应把模型速度、代码测试数量或材料数量直接等同于评委得分。下一步最有价值的是补齐评委评语、答辩问题和现场记录，再把改进项映射到具体评分维度。

### 工作区没有形成干净的最终冻结点

归档时基线提交为 `d6e707a`，工作区还有两处未提交前端改动。虽然补丁已保存，但这意味着“比赛结束时展示的版本”和“仓库提交版本”并不完全相同。下一次比赛应在提交前建立一个干净提交或只读发布包，并把演示视频、PPT 和源码统一从这个版本导出。

### 材料命名和内容边界需要再核对

归档文件中有华章有据的品牌、讲稿、部署地址和验收数据。它们可以作为工程过程参考，但在确认它们确实属于 `PC-Studio` 之前，不应把其中的功能、测试数字和线上链接直接写入 PC-Studio 的对外复盘。这个边界已经在本归档说明中标出，后续需要由队伍成员完成一次人工认领。

## 4. 下一阶段优先级

### P0：统一最终身份

逐份检查 PPT、视频片尾、说明书封面、网页标题、Logo、压缩包和链接，把主身份统一成 `ZJUshaaa / PC-Studio`。检查通过后重新生成一份“最终提交包”，旧材料放入历史版本目录。

### P0：补一份最终提交索引

记录队伍、项目、比赛赛道、最终排名、奖项、文件名、SHA-256、导出时间、演示版本和提交链接。索引和最终结果截图放在同一层，任何人打开归档都能先确认“这是谁的哪一版作品”。

### P1：补齐评委反馈与答辩记录

把评委原话、提问、现场演示中断点和临场修改记录下来，再把问题按创意、技术、交互、表达和完成度分类。没有反馈时，明确标记为未知，不用模型测试数据替代。

### P1：建立下一次比赛的冻结流程

比赛前一天冻结源码和素材，生成干净提交；比赛当天只从冻结包演示；比赛结束后把最终结果、现场版本和提交版本放进同一份清单。这样可以减少“文件在，但不知道是哪一版”的情况。
