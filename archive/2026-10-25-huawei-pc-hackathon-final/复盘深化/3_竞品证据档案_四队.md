## 结论先行

- **"爆文蒸馏"只有稿研做实了**（复赛录像证据：376 篇候选 → 102 篇精读 → 14 篇公众号深度蒸馏，用 Codex Computer Use 破反爬；无公开代码可复核）。byai 曾做小红书实时笔记抓取但已整体移除；MateQuill 只有 5 条人工案例；门店助手做过一次失败的人工案例研究。

- **"连续性修改"三家都有**：byai（版本号/冲突保护/patch）、MateQuill（接受/修订/重选+反馈记忆）、门店助手（Plan/Draft 编辑器+版本恢复）。

## 对 v1 初评的复核修正

1. **"前两名做了蒸馏"**：不成立。蒸馏只有稿研做实（录像证据，无代码）；byai 的热点是热榜+热梗，且小红书实时抓取已移除。
2. **"店员自主创造在前两名"**：不成立。实锤在 MateQuill（第 3）；byai 是编辑交付，门店助手是受约束编辑。
3. **MateQuill 需要登录**：修正——直连 API 401，但"直接试用"发访客会话，评委无需账号。
4. **byai 语义核验**：其 readiness 自认 not_implemented（确定性规则扫描 + 模型复核），不是完整语义核验——这在 v1 初评中未明确。
5. **PC-Studio 定位**：证据链/核验深度（逐字段引用 + 独立评审 + 修订后复审）在四家可查代码里是唯一完整闭环；失分不在技术，在展示权重与内容侧证据缺失（见 1_、2_）。
